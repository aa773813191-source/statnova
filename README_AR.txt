STATNOVA V11.2 — تحسين تقارير Word وPDF

محتويات الحزمة:
- app_v11_final.py: ملف التطبيق المحدّث.
- requirements.txt: المكتبات المطلوبة، بما فيها مكتبات Word وPDF وSPSS.
- NotoNaskhArabic-Regular.ttf: الخط العربي المستخدم في PDF.

تحديثات Word:
1) تقرير Word العادي: جداول فعلية قابلة للتحرير لجودة البيانات، أنواع المتغيرات، القيم المفقودة، الإحصاءات الوصفية، ونتائج التحليل.
2) تقرير Word الذكي: أقسام منظمة وجداول فعلية لمؤشرات جودة البيانات، الإحصاءات الوصفية، مصفوفة الارتباط، تكرارات المتغيرات الفئوية، ونتائج الاختبارات.
3) إدراج الرسوم التوزيعية الفعلية داخل Word، مع فصل قسم الرسوم لتقليل ازدحام الصفحات.
4) ضبط اتجاه الفقرات العربية من اليمين إلى اليسار، مع الاحتفاظ بإمكانية تعديل النصوص والجداول داخل Word.
5) إدراج التفسيرين الإنجليزي والعربي ومعلومات الدراسة وحدود التفسير.

التحديثات السابقة المحفوظة:
- تقارير PDF الذكية تتضمن بيانات الدراسة، جودة البيانات، الإحصاءات الوصفية، الارتباطات، التفسيرات والرسوم المتاحة.
- Excel يتضمن أوراق جودة البيانات والإحصاءات الوصفية والارتباطات والملف الكامل.
- دعم CSV وSPSS SAV عند توفر المكتبات المطلوبة.

طريقة الرفع:
1) ارفعي app_v11_final.py إلى مستودع GitHub واستبدلي الملف الحالي بالاسم نفسه.
2) ارفعي requirements.txt واستبدلي النسخة الحالية.
3) ارفعي NotoNaskhArabic-Regular.ttf إلى جذر المستودع بجانب ملف التطبيق.
4) لا تغيّري مسار ملف التطبيق في إعدادات Streamlit؛ اتركيه app_v11_final.py.
5) انتظري اكتمال إعادة النشر، ثم اختبري تنزيل Word وPDF على ملف البيانات نفسه.

التحقق:
تم فحص صياغة Python بنجاح. لم يُنفّذ اختبار متصفح حي أو اختبار فتح ملفات Word/PDF على بيئة Streamlit المستضافة؛ لذلك يجب اختبار التنزيل بعد النشر قبل اعتماد النسخة نهائيًا.
